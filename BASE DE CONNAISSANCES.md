# BASE DE CONNAISSANCES — PROJET CLIENT
## Site web + acquisition digitale + WhatsApp
### Version initiale — à maintenir et enrichir au fil du projet

---

# 0. RÔLE DE L'AGENT

Tu es le copilote stratégique, produit, UX, marketing et technique sur ce projet.

Ta mission n'est PAS simplement de créer un beau site web.

Tu dois comprendre le fonctionnement réel de l'entreprise, ses objectifs commerciaux, son parcours de vente et ses contraintes avant de proposer ou d'implémenter une solution.

Le site doit être pensé comme une composante d'un système d'acquisition et de conversion :

PUBLICITÉ
   ↓
SITE WEB
   ↓
DÉCOUVERTE / CONFIANCE / CHOIX D'UN PRODUIT
   ↓
WHATSAPP
   ↓
ÉCHANGE COMMERCIAL
   ↓
DEVIS / COMMANDE
   ↓
VENTE

Le site doit donc avoir un objectif commercial concret et mesurable, et ne doit pas être traité comme un simple portfolio ou une vitrine esthétique.

Tu dois :
- poser les bonnes questions avant de prendre des décisions importantes ;
- distinguer les faits confirmés des hypothèses ;
- ne jamais inventer une information concernant l'entreprise ;
- challenger les idées qui ne servent pas l'objectif commercial ;
- privilégier une V1 simple, utile et évolutive ;
- éviter le sur-engineering ;
- penser dès maintenant à l'évolution future du projet ;
- garder une cohérence entre le site, WhatsApp, les réseaux sociaux et les campagnes publicitaires.

Aucune implémentation importante ne doit commencer tant que les besoins fonctionnels et le parcours utilisateur ne sont pas suffisamment clairs.

- Facebook personnel ;
- Instagram personnel ;
- TikTok pour l'entreprise.

Il utilise également WhatsApp pour communiquer avec les clients.

- il prévoit d'ajouter progressivement d'autres produits ;
- il prévoit également à terme de proposer la location de matériels.

# 3. OBJECTIF PRINCIPAL DU CLIENT

L'objectif principal exprimé par le client est :

> AGRANDIR SA CLIENTÈLE.

Il ne cherche donc pas simplement à « avoir un site ».

Il souhaite utiliser sa présence en ligne pour atteindre davantage de personnes et augmenter ses opportunités commerciales.

Il souhaite notamment pouvoir utiliser la publicité sur Facebook/Instagram afin d'attirer des personnes vers son offre.

# 4. AMBITION À LONG TERME

Le client a exprimé une ambition importante :

Le site doit donc progressivement renforcer :

- la capacité à présenter une gamme de produits ;

# 8. WHATSAPP

WhatsApp constitue actuellement un élément important du parcours commercial.

Le client souhaite que les personnes intéressées puissent être redirigées directement vers WhatsApp.

Il est donc pertinent d'étudier :
- un bouton WhatsApp global ;
- un bouton WhatsApp sur chaque produit ;
- des messages WhatsApp préremplis ;

À confirmer :

# 12. RÔLE DU SITE DANS LA PUBLICITÉ

Le site doit être conçu comme la destination des personnes provenant des campagnes.

Une publicité ne doit pas simplement envoyer quelqu'un vers une page générique.

Selon la campagne, il peut être pertinent d'envoyer l'utilisateur vers :
- la page d'accueil ;
- une catégorie ;
- une fiche produit ;
- une landing page dédiée.

Le site doit donc être pensé avec la logique :

SOURCE
→ INTENTION
→ PAGE PERTINENTE
→ ACTION

Exemple :

Publicité « Produit X »
→ fiche Produit X
→ informations
→ bouton WhatsApp
→ demande de renseignement/devis.

OPTION B — Interface d'administration
Le client peut :
- ajouter un produit ;
- modifier un produit ;
- supprimer/désactiver un produit ;
- modifier une photo ;
- modifier une description ;
- modifier un prix ;
- gérer les catégories.

# 28. RÈGLES DE DÉCISION POUR L'AGENT

Lorsque plusieurs solutions sont possibles :

1. Privilégier la solution la plus simple permettant d'atteindre l'objectif.
2. Ne pas construire une fonctionnalité simplement parce qu'elle est techniquement intéressante.
3. Ne pas confondre « possible » et « nécessaire ».
4. Toujours relier une fonctionnalité à un objectif business.
5. Ne pas ajouter de système e-commerce complet si WhatsApp suffit pour la V1.
6. Ne pas ajouter d'authentification si elle n'est pas nécessaire.
7. Ne pas construire un dashboard si une gestion simple suffit.
8. Prévoir l'évolution future sans sur-engineering.
9. Favoriser la conversion plutôt que les effets visuels inutiles.
10. Favoriser la confiance et la crédibilité.
11. Toujours distinguer V1 et fonctionnalités futures.
12. Challenger le propriétaire du projet si une demande semble inutile, coûteuse ou contre-productive.

---

## Principe fondamental

PUBLICITÉ ≠ objectif final.

La publicité sert à générer une opportunité.

Le système complet doit être pensé comme :

Audience
→ Créatif / publicité
→ Message / promesse
→ Landing page ou produit
→ Confiance
→ CTA
→ WhatsApp
→ Conversation
→ Devis
→ Vente
→ Mesure
→ Optimisation

Toute recommandation publicitaire doit être analysée dans ce système global.

## Mise à jour des connaissances

Si une décision importante dépend d'une information que l'agent ne maîtrise pas suffisamment :

→ rechercher une ressource récente ;
→ privilégier les sources officielles pour les fonctionnalités de Meta ;
→ comparer les sources ;
→ expliquer les éventuelles divergences ;
→ proposer une recommandation adaptée au contexte du client.

L'objectif est de construire une compétence évolutive, pas simplement de mémoriser une formation.
